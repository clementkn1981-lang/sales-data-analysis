# Sales Data Analysis

## Project Overview
This is a junior data analyst portfolio project that analyzes sales data to identify product and regional sales trends.

## Tools Used
- SQL
- Excel
- CSV
- GitHub

## Dataset
The dataset contains sales transactions with the following fields:
- Date
- Product
- Region
- Sales

## SQL Analysis
The SQL analysis answers several business questions:
- What are the total sales?
- Which products generate the most sales?
- Which regions generate the most sales?
- What are the top 5 products by sales?

## Key Insights
- Laptops generated the highest sales in the sample dataset.
- Sales performance varies across regions.
- SQL aggregation was used to compare products and regions.
- The analysis helps identify the strongest-performing products.

## Files
- `sales_data.csv` — Sales dataset
- `sales_analysis.sql` — SQL queries used for the analysis
